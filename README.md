# Faceless Finesse

An AI-guided web app that helps beginners and existing creators pick an easy-to-rank micro-niche, generate scripts, text/image/video posts, and auto-post to YouTube, Facebook and X on a 30-day calendar.

Built as a **Whop App** (Whop handles login, paywall, 3-day free trial and billing), hosted on **Cloudflare Workers** (via OpenNext), with **Supabase** for data.

## Status
Planning complete. The app is being built in stages via pull requests.
